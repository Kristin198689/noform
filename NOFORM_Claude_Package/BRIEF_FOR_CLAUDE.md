# NØFORM - финальный пакет для Claude
Версия 1.0 / 24 октября 2026. Языки: de (основной), en, uk. Код языка украинского uk, не ua.

## Инструкция к началу
Это имиджевый сайт вымышленного streetwear-бренда, портфолио Volodina Web Studio. Нет магазина, оплаты, аккаунтов, базы данных, заказов и форм. Создать цельный адаптивный сайт по восьми макетам references/. Не вставлять скриншоты макетов как готовые секции. Использовать чистые фото из assets/, текст и графику собирать кодом. Не использовать чужие Instagram-фото в опубликованном сайте. Не генерировать новые фотографии вместо предоставленных.

Приоритет: этот файл и messages.*.json > подписи, случайные цифры и неточности на AI-макетах > старый бриф. Макеты задают композицию, но не являются точным чертежом букв. Использовать единый SVG-логотип assets/noform-wordmark.svg; это шрифтовой базовый вариант для всей реализации. Не трассировать чужой ORIGIN. Маленькая капсула ORIGIN на утверждённом херо пока сохранена как запрос пользователя; это не название сайта и не указание на чужое авторство. Не размножать её по остальным секциям.

## Порядок и навигация
01 HERO -> переход A (серый) -> 02 FORM IN MOTION -> 03 ABOUT -> переход B (чёрный) -> 04 VISOR -> 05 DESIGN CODE -> 06 SCANNER -> 07 FORM LAB -> 08 FINALE.
Переходы не получают отдельных номеров меню. INDEX [ + ] виден уже в херо и фиксирован дальше; открывает полноэкранный индекс 01-08. На херо отсутствуют CTA, бургер и обычная полоса меню. Внутри индекса доступен DE / EN / UK; компактный выбор языка можно разместить рядом с INDEX, не перекрывая слоган. Не дублировать фиксированные элементы из каждого макета: одна навигация, один переключатель звука. Escape закрывает меню, фокус заперт внутри открытого меню и возвращается к кнопке; пункты настоящие ссылки на якоря текущего языка. По клику пунктов не проигрывать все промежуточные сцены заново.

## Палитра и типографика
Основной фон #080808; светлый текст #F6F5F2; фон пауз и лаборатории #D9D9D6; нейтральный #A0A0A0; charcoal #292A30; фуксия #FF168A; taupe #BAB5AA только запасной тон. Фуксия обычно до 2-3% площади, на херо заметно меньше; без сильных бликов. На чёрном сетка белая с opacity 0.12-0.22, на сером чёрная с opacity 0.12-0.2; 1 CSS px. Содержательные подписи должны иметь достаточный контраст, не путать их с почти невидимой декоративной сеткой.
MuseoModerno 700-800: логотип/латинские заголовки; Golos Text 400-500: основной текст всех языков, 800 для украинских заголовков; IBM Plex Mono 400: микронадписи. MuseoModerno не содержит украинской кириллицы - проверено по cmap вложенного файла. Не имитировать кириллицу латинскими похожими буквами. Файлы WOFF2/TTF и OFL вложены. Бренд NØFORM и модель VISOR 01 неизменны; содержательные заголовки, слоганы, меню и подписи переводить. Макеты на английском являются только визуальными примерами.

## Шрифты и приватность
Подключать только вложенные локальные WOFF2 с собственного домена через @font-face из spec/design-tokens.css либо next/font/local. Запрещены runtime-запросы fonts.googleapis.com, fonts.gstatic.com, Adobe Fonts и CDN шрифтов. Не использовать next/font/google или remote @import. Сохранить OFL.txt в проекте. Самохостинг исключает запросы к внешнему поставщику шрифта, но сам по себе не является гарантией соответствия всего сайта GDPR. Проверить Network при первом заходе/переключении языков: font-ресурсы только same-origin. Не добавлять аналитику, пиксели, внешние видео/карты и cookies по умолчанию.

## Общая реализация
Предлагаемый стек: Next.js/React + TypeScript. SSR/SSG для контента; клиентские островки только для сцен. Выбрать один инструмент таймлайнов (например GSAP с ScrollTrigger) или Motion, установить как зависимость сборки, не подключать CDN. Не смешивать несколько систем плавного скролла. Для кольца достаточно CSS perspective/transform или WebGL при обоснованной необходимости; сами фотографии не 3D-модели. Уборка всех listeners/timelines при смене маршрута. Контент виден без JS, нет пустого canvas вместо всего сайта. Не нужен backend. Публикация/домен только отдельным шагом после проверки.

## Сценарии движения
Hero: спокойное появление подписи, никакого постоянного движения лица. Пауза A: 40-55svh, фраза SPACE TO BE YOURSELF; слабое раздвижение букв. Лукбук: камера неподвижна, изображения расположены на кольце с перспективой, прокрутка даёт около одного оборота за ограниченный участок 180-240svh; после него обычный выход вниз. При обратном скролле обратное вращение. Drag/swipe меняет угловое смещение; изображения повторяются по кругу, но сама страница не застревает бесконечно. Передняя панель читаема, задние меньше/приглушены. Не показывать одновременно три огромных пары очков: один основной предмет, другие ракурсы для аккуратной смены; это отдельные генерации, не точный turntable. Короткий звук только после SOUND ON и движения через шаг, throttling, низкая громкость, без автозапуска. Синтезировать Web Audio щелчок без внешней музыки.
About: спокойное чтение с последовательным появлением тонких линий. Пауза B: 40-60svh, прорисовка SVG-визора и CHANGE YOUR PERSPECTIVE; короткое растворение в VISOR. VISOR: слабое увеличение не более нескольких процентов, линии-указатели поверх, подписи не закрывают очки. Design Code: прорисовка контуров, максимум небольшой photo-thumbnail. Scanner: розовая линия сканирует три слова, контуры открывают изображения только внутри масок букв; ниже/до прохода - контур, после - фото. Изображение может немного смещаться внутри маски. Участок около 140-180svh, не бесконечный. Lab: input range 0-100 управляет совместимыми SVG paths худи, без реальных размеров и подбора одежды. Финал: линии сходятся к логотипу, короткий розовый пробег по контуру при hover; на touch одно появление.
Для prefers-reduced-motion: статичные композиции, галерея как обычный доступный список/горизонтальный скролл без пиннинга, фактуры в буквах уже открыты, range меняет форму без инерции. Вкладка скрыта/сцена вне экрана - таймлайны остановлены.

## Адаптивность и доступность
Десктоп 1440: поля 40-64px, 12 колонок. Планшет 768: 6 колонок, поля 24px. Телефон 360-430: поля 16-20px, одна колонка. About: фото над текстом; Design Code: исследования вертикально; Lab: худи над ползунком, весь контрол доступен пальцу. Не обрезать смысл при переводах: немецкий длиннее, украинский имеет другой шрифт. Body 16-20px, line-height 1.5-1.65; рабочие подписи 11-13px минимум, управление языком/меню не микроскопическое. Чисто декоративные цифры могут быть мельче и aria-hidden. Не растягивать кожу и очки; object-fit:cover с отдельной focal point. Фронтальный портрет на телефоне кадрировать по центру лица. Одна H1, остальные H2; контраст, skip-link, клавиатура и видимый фокус; звуковой переключатель aria-pressed; фотографии с alt из словарей, декоративные дубли с пустым alt.

## Ассеты и качество
Все references/*.png - только визуальные ориентиры; production-source - assets/photos и assets/products. Карта в asset-manifest.json с SHA256. Херо hero-clean.png; About look-01-low-angle.png; VISOR visor-front-clean.png. Лукбук 5 look-фото, 3 ракурса очков + hoodie-cutout/cargo-cutout. Продуктовые PNG имеют настоящий alpha, проверены на белой подложке; отражения зеркальных линз оставлять непрозрачными по смыслу. Не заменять прозрачность серым/чёрным прямоугольником. Сохранять PNG master; для сайта производные AVIF/WebP, в том числе с alpha. Артефакты AI/мелкие отличия ракурсов возможны: не обещать точные характеристики реального товара.
Макеты 05-08 теперь созданы, а не только описаны. Файл 07 может содержать случайные mm/scale; заменить их условным VOLUME 0-100. Цифры геометрии в 05 также декоративны, не реальные спецификации очков. Розовые линии и шрифты в генерациях ориентировочны - следовать токенам.

## Критерии приёмки
1. Все 8 секций и две паузы в правильном порядке, никаких старых синих вариантов. 2. Все чистые фото соответствуют карте; скриншоты не используются вместо HTML. 3. Одна модель/визор во всех ракурсах. 4. Полная работа de/en/uk и проверка ІЇЄҐ/äöüß. 5. Font requests только same-origin; OFL сохранены. 6. Альфа объектов прозрачная на разных подложках. 7. Кольцо вращается и отпускает прокрутку, drag и клавиатура не конфликтуют. 8. Scanner держит фото внутри букв. 9. Lab работает пальцем и клавиатурой. 10. Sound off при первом заходе, нет звука без жеста. 11. Reduced motion, iOS Safari и узкий экран проверены. 12. Нет горизонтального overflow страницы, CLS из-за шрифтов/картинок, ошибок консоли. 13. Hero priority, остальные lazy, указаны размеры; оптимизированные web-ассеты, не грузить все PNG сразу. 14. npm build/typecheck/lint по проекту, визуальная проверка 360/390/768/1440 и переключения языков. 15.
